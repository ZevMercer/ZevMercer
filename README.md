### 🚀 About Me

> Building games and the tools to build them — from a phone, on the go.

- 🎮 **Game Dev** focused on **top-down / arcade** experiences with **LÖVE 2D (Lua)**
- 📱 I build **Android-first dev tools** so coding games doesn't need a desktop
- 🛠️ Creator of **PlayForge** (2D engine) and **Love CodeX** (LÖVE editor for Android)
- ⚡ I like neon, synthwave aesthetics, and making things *feel* polished
- 🌱 Always learning: shader tricks, procedural generation, tooling
